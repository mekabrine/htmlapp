# Voice attachments and durable app conversations — 1.9.17

While dragging the Library, running-app edit, or Forge edit microphone, three large targets appear at the top: Camera, Photos, and Files. Releasing on a target stops capture but defers Whisper decoding until selection is complete. Picker cancellation does not submit an AI request. A successful selection opens Review Request and transcribes the captured request into an editable text field. Nothing is sent to Forge until Generate is pressed. Cancel dismisses the review without generating. The handoff discards retained retry audio before forwarding the edited transcript, so it cannot be replaced by another transcription.

The review accepts up to nine mixed attachments, shown in a three-column grid (at most three rows). Camera, Photos, and Files buttons add more references without submitting; Photos is limited to the remaining capacity and excessive file selections are rejected explicitly. Camera capture accepts one photo. Each square shows a cropped photo or file-type symbol and filename. The × button asks for confirmation before removing an item from this request; original files are untouched. Preview images are downsampled to 400px and retained while editing the transcript. Review buttons use Liquid Glass on iOS 26, with compatible styles on older versions: Generate is blue/white and Cancel is gray/red.

Images are normalized to JPEG at up to 1600px and sent as image content through the configured OpenAI-compatible or Anthropic message format. The selected model must support vision. Files accept UTF-8 text/code up to 160 KB per file and readable-text PDFs; originals must be under 8 MB. Image-only PDFs require page screenshots. Unsupported data produces an explicit error rather than sending just a filename. Text and PDF contents are included as reference data. Offline Forge accepts text references; image requests remain available for an online vision model.

Normal cold launches show a neutral loading surface while a shared asynchronous prewarm decodes the Library off the main actor. The Library view mounts only after loading finishes; an unreadable snapshot still uses the existing backup/recovery safeguards. The initial routing grace period and direct URL LaunchCache path remain in place, so URL launches can open an app without first loading the Library.

Images can also be used as real app assets: the coding request names a stable attachment token, and the host embeds the selected JPEG into the generated HTML when that token is used. Request attachments are cached privately for background-result recovery and removed after saving or explicitly discarding the request; saved app images remain embedded in its HTML.

Question planning can return NO_QUESTION. Unresolved substantial choices get one question; ordinary design choices use defaults. Text changes, focus changes, and taps reset a five-second inactivity deadline. The current typed answer is used when nonempty, otherwise Forge's recommendation is used. Inactive/background transitions resolve a pending question immediately and allow the existing background request handoff. Background upload bodies include the same attachment inputs and history context. iOS suspension, force-quit, lost connectivity, and provider limits can still stop or delay work; foreground QA remains necessary after a background result.

App Conversation is available from Library → app menu → AI Edit History. It is an append-only JSONL log in Application Support/HTMLApp/ConversationLogs. Requests, bounded technical outcome summaries, questions/answers, saved and unsaved reverts, and completed export/nearby share events accumulate without automatic pruning. Recent bounded context informs subsequent edits. Share destinations are observations, not automatic evidence of user approval. Cancelled shares are not logged as completed shares. Private backups contain full conversation entries; nearby packages without personal data exclude them. Imports merge stable entry IDs to avoid duplication. Original attachment bytes are request inputs, not retained forever in this conversation log.

## Manual validation

- Exercise Camera, Photos, Files, cancellation, denied camera access, and unsupported/oversized files from each microphone entry point, with Apple Speech and Whisper.
- From each entry point, mix camera photos, Photos selections, a PDF, and a text file. Verify the three-column grid, nine-item limit, additional-picker cancellation, remove/keep confirmation, and original-file preservation.
- Change the transcript after Whisper finishes. Add another attachment and press Generate: only the edited prompt and remaining references must be sent, once. Verify no generation begins while reviewing or after Cancel. Test failed transcription followed by typing a prompt manually.
- Check blue/white Generate and gray/red Cancel, other glass buttons on iOS 26, and fallback styles on iOS 16.2. Test a small phone, iPad, large Dynamic Type, landscape, and the keyboard.
- Cold-launch with a populated Library: no empty-library message should flash. Cold-launch an app URL and verify the direct launch skips the Library; close the app and verify the Library then loads normally. Verify first launch with no saved apps still reaches the actual empty state, and damaged-library recovery still protects saved data.
- Verify the selected model receives image content and actual text/PDF contents; compare the generated change against the reference.
- While a question is visible, type repeatedly for more than five seconds. It must remain visible until five seconds after the final interaction. Then test idle timeout and locking mid-question.
- Confirm a locked-screen provider request can finish through the existing background path, and foreground verification resumes on reopening. Do not claim uninterrupted execution on all iOS versions.
- Save multiple edits, undo a draft, restore an older saved checkpoint, complete and cancel a share, restart HTMLApp, and inspect App Conversation.
- Export a private backup and restore it; verify original timestamps and IDs survive and repeated merges do not duplicate events. Confirm non-personal nearby exports contain no conversations.

Local source/bridge checks do not compile UIKit, PHPicker, SwiftUI, or native XCTest. Those checks require the user's manual build/device validation.
